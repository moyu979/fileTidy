# 存储结构

本项目的存储结构分成三层

## 硬件层

命名为storage，作为硬件（SSH，HDD，磁带）等的抽象

## 存储层

命名为Volume，作为可独立使用的存储空间的抽象

## 检查层

命名为VolumeGroup，作为校验机制的抽象

## 硬件-存储结构

本项目认为，一个存储层可以建立在多个硬件之上（例如raid机制或磁带的跨磁带机制），同时，也可能多个存储层共享一个硬件（例如硬盘的分区机制），因此，使用一个storage-volume过度层存储这些结构

## 存储-检查过度层

本项目使用snapraid进行磁盘的检查，使用自建的磁带raid5和raid1（待完成）进行磁带的检查，因此使用一个存储-检查过度层记录，本项目认为，一个存储空间可以存在于多个检查层
