# 这是什么

这是自用的一个文件管理系统，主要功能为登记冷数据硬盘，并为其提供对应的缓存，记录，校验等功能

# 项目结构

本项目自顶向下，分成如下结构

## 顶级结构

### fuse文件管理模块

用于在操作系统中建立新的文件系统，以便对文件进行类似本地文件的管理

### api模块

为管理终端提供的一组接口，用于管理文件，

## 文件管理集

用于为fuse文件系统提供一个相对统一的接口，防止cache层暴露，同时，在文件不存在等情况下，通过api接口提示用户进行硬件的更改

## 文件缓存层

利用热阵列进行缓存管理，保证访问率较高的数据往往能够缓存命中

## 设备层

### device

用于管理硬盘和磁带的硬件层，将不同的硬件抽象为统一的接口，包括检查，替换等功能

### volume

用于独立的文件系统的管理，在本项目中，认为volume对应着最简单的，可独立挂载的文件系统，例如ntfs在windows下的磁盘，挂载点，zfs文件系统的存储空间等

### superVolume

超卷，用于多个卷能够进行交叉校验时，管理交叉校验卷
